# Applyra: prioritized SaaS feature roadmap

These are proposed additions, not a claim that they are all implemented.

| Priority | Feature | Practical outcome |
|---|---|---|
| P0 | Live auto-apply acceptance and portal diagnostics | Detect missing buttons, expired sessions and screening blockers; show the precise failure and safe retry |
| P0 | Full payment lifecycle | Verified purchases activate the right plan; upgrades, renewals, cancellations, refunds and invoices stay consistent |
| P0 | Hosted scan scheduler | Daily/weekly/monthly scans run with browser closed; timezone settings, email digest and delivery history |
| P0 | Verified India and global job providers | More useful ML/MLOps, Data & AI, BI, Python automation and analytics opportunities with clear source coverage |
| P0 | Complete resume/job/profile evidence | Resume upload, extraction review, explicit gaps and candidate-scoped data with visible unknowns |
| P1 | Role-specific resume versions and change review | Suggest truthful edits per role, preserve history, export selectable PDF/DOCX |
| P1 | Naukri and LinkedIn improvement coach | Section-by-section headline, About, skills and project recommendations users review before publishing |
| P1 | Resume/profile consistency checks | Highlight conflicting dates, titles, experience, location and skills before applying |
| P1 | Application conversion analytics | Track submitted → shortlisted → interview → offer; compare role/variant/source results without false causal promises |
| P1 | Application review queue | Show fit, resume version and answers before submission; daily caps, pause and audit trail |
| P1 | Follow-up and interview reminders | Schedule reminders from actual application state and dates |
| P1 | Interview preparation grounded in each JD | Practice technical questions, project explanations and gap-focused learning plans |
| P1 | Compensation provenance | Display listing date, location, experience, salary component and sample confidence; distinguish stated and estimated pay |
| P1 | User data controls | Export/delete resumes and profile evidence, scoped retention and account separation |
| P2 | Skill demand trends and project plans | Compare repeated requirements and recommend achievable portfolio projects |
| P2 | Portfolio/GitHub evidence import | Link claims to demonstrable projects and contributions |
| P2 | Saved searches and company watchlists | Alert on new roles, changed requirements and application deadlines |
| P2 | Recruiter communication drafts | Generate personalized drafts from supplied context; users approve sending |
| P2 | Duplicate, stale and suspicious listing detection | Avoid wasting applications and identify unsupported listing claims |
| P2 | Team and agency workflows | Multiple candidates, assigned reviewers, role permissions and tenant separation |
| P2 | Accessibility and responsive onboarding | Keyboard-friendly flows, readable status/error states and resumable setup |
| P2 | CRM/calendar integrations | Connect application tracking and interview scheduling with explicit user control |
| P2 | Localization and currency-aware billing | Region-specific copy, taxes and payment options based on supported merchant setup |
