# Applyra 2.9.0.1 repair

1. Extract this archive.
2. In chrome://extensions enable Developer mode, then Load unpacked and choose this folder (or reload your existing unpacked extension).
3. Use the sidebar **Resume Analysis** link. Upload, review and save the resume; add Naukri/LinkedIn snapshots.
4. Use the sidebar **Scheduled Scans** link. Scan now runs immediately from your settings; Save schedule persists the recurring schedule. Enable recurring scans for automatic execution.
5. Open Auto Apply and preview the jobs before starting a recommended run. Live Naukri acceptance still needs testing in your account.
6. Open Comp Radar to inspect observed salary evidence.
7. Billing requires deployed backend functions, active server-published plans and merchant setup. Additional gateways are preview code, not live payments.

Read docs/2.9.0-IMPLEMENTATION.md for the precise release status, limitations and payment deployment work. Read docs/SAAS-FEATURE-ROADMAP.md for the prioritized feature list. This is an implementation preview, not a claim that all requested features are production-ready.

If these links are missing, check the installed extension version is 2.9.0.1, reload it in chrome://extensions, close old Applyra tabs and reopen the dashboard. If loading a new directory, disable older duplicate Applyra installations.
